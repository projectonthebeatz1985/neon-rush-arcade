NEON RUSH ARCADE — PROJECT DESIGNS

UPDATE AND PUBLISH
1. Extract this ZIP.
2. In your GitHub repository neon-rush-arcade, choose Add file > Upload files.
3. Upload/replace index.html, manifest.webmanifest, and sw.js, plus any changed icons.
4. Commit changes. GitHub Pages will update automatically.
5. On phones, close the old installed app/browser tab and reopen the website. If it still shows the old version, clear the site cache or wait a minute for the service worker update.

RESPONSIVE DESIGN + INSTALL
The game now adapts to phone, tablet, and desktop screens. The Install App button gives browser-specific instructions. Supported Chromium browsers can show a native install prompt. On iPhone/iPad use Safari > Share > Add to Home Screen.

GLOBAL LEADERBOARD SETUP (FREE SUPABASE PROJECT)
The leaderboard UI is ready, but shared scores need a Supabase project. Until configured, personal bests continue saving locally on each device.
1. Create a free project at https://supabase.com/
2. In Supabase SQL Editor, run:

create table public.scores (
  id bigint generated by default as identity primary key,
  player_name text not null check (char_length(player_name) between 1 and 18),
  score integer not null check (score >= 0),
  created_at timestamptz not null default now()
);
alter table public.scores enable row level security;
create policy "Anyone can read scores" on public.scores for select using (true);
create policy "Anyone can submit scores" on public.scores for insert with check (true);

3. In Supabase Project Settings > API, copy the Project URL and anon/public key. Never use the service_role key in a browser app.
4. Open index.html and find SUPABASE_URL and SUPABASE_ANON_KEY near the top of the game script. Paste the Project URL and anon/public key between the quotes.
5. Upload the updated index.html to GitHub. The Leaderboard button will then load shared scores and completed runs will submit scores.

NOTE: This simple public leaderboard is open to anonymous submissions and can be cheated/spammed. It is suitable for a casual free game; competitive anti-cheat would require server-side validation/rate limiting.
